# Norka — публикация итогов розыгрыша

Изолированный модуль для публикации **одной общей PNG-карточки** со всеми победителями розыгрыша по номерам.

## Правила

- Поддерживается только item.type === "numbers" и item.status === "completed".
- От 1 до 25 победителей на одной карточке.
- В каждой строке: аватар (или фирменная заглушка с инициалами), имя, номер билета и приз.
- Одна публикация в канал из Redis norka:channel:chat_id.
- Одна кнопка MAX open_app: «🌿 Открыть Норку».
- В личные сообщения изображения не отправляются.
- Redis-lock и ключ опубликованного результата защищают от повторной отправки при повторном lifecycle.
- Слот канала резервируется через Redis с интервалом 600 мс (не более 2 публикаций в секунду).
- При ошибке публикации ключ успеха не записывается; lifecycle может повторить попытку.

## Файлы

- publisher.js — загрузка картинки в MAX, публикация, Redis-lock и idempotency.
- winner-card.js — рендер общей карточки на основе исходного шаблона.
- winner-template.part01.b64 … winner-template.part04.b64 — четыре части исходного PNG-шаблона. Модуль собирает их автоматически, поэтому отдельный бинарный файл при переносе не нужен.
- package.json — зависимость sharp.

## Подключение

Смотри integration-snippets.md. Этот модуль нужно подключить к api/norka.js после сохранения результата розыгрыша и в lifecycle-повторе. До подключения он не влияет на действующий backend.

## Переменные и окружение

- MAX_BOT_TOKEN — токен действующего MAX-бота Норки.
- Redis-команда передаётся из текущего api/norka.js, поэтому используются уже существующие Redis URL и токены без дублирования настроек.
- Требуется Node.js 22 и пакет sharp версии ^0.34.5.
- Для MAX API нужны два сертификата в certs/ в корне функции:
  - russian_trusted_root_ca.pem
  - russian_trusted_root_ca_gost_2025.pem

## Проверка рендера

После установки sharp можно вызвать renderWinnerCard из winner-card.js, передав item, массив winners и при необходимости templatePath. Функция возвращает PNG-буфер.

Пример объекта победителя:

\`\`\`js
{
  place: 1,
  number: 17,
  userId: "123456789",
  name: "Имя участника",
  avatar: "https://example.com/avatar.jpg",
  prize: { title: "Подарочный набор" }
}
\`\`\`

Обычные посты в канале этот модуль не обрабатывает и на них не отвечает.
