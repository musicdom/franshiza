# Гармоника — музыкальное мини-приложение

Личная музыкальная библиотека с плеером. В каталоге нет предустановленных песен и отключён автоматический поиск по внешним музыкальным сайтам. В библиотеку попадают только треки, которые администратор добавил вручную.

## Возможности
- Встроенный плеер с play/pause, переключением треков и перемоткой.
- Избранное сохраняется локально у слушателя.
- Каталог и поиск работают только по трекам, добавленным администратором.
- Админ-панель позволяет добавлять, редактировать и удалять треки.
- Метаданные сохраняются в существующем Redis/KV в Vercel.
- Публичные ссылки Яндекс Диска преобразуются сервером в временную ссылку скачивания перед воспроизведением.

## Настройка админ-панели

В проекте Vercel `franshiza` должны быть переменные:
- `MUSIC_ADMIN_PASSWORD` — пароль администратора.
- `KV_REST_API_URL` и `KV_REST_API_TOKEN` (или соответствующие `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`) — доступ к существующему хранилищу Redis/KV.

После изменения переменных окружения нужен новый production deployment.

Открой мини-приложение и нажми **Админ**. Введи `MUSIC_ADMIN_PASSWORD`, чтобы открыть редактор. Добавь название, исполнителя и публичную HTTPS-ссылку на аудио; обложка необязательна. Ссылка Яндекс Диска должна быть публичной, с разрешённым скачиванием. После сохранения песня появится в каталоге у слушателей.

## Ограничения ссылок Яндекс Диска

Ссылка формата `https://disk.yandex.ru/d/КОД` — это публичная ссылка, а не постоянный URL MP3. Сервер запрашивает у API Яндекс Диска временный URL скачивания. Поддержка воспроизведения, перемотки и доступность без VPN зависят от самого файла и поведения Яндекс Диска в MAX WebView; это нужно проверять на реальном устройстве.

## Права на музыку

Добавляй только аудиофайлы, на хранение и распространение которых у тебя есть права или разрешение.

## Публикация

GitHub Pages использует статический `index.html`; API и хранилище работают на Vercel.
