# Норка — MAX Mini App

Норка — приложение с двумя внутренними балансами: ягодами и монетами.

## MVP
- Ягоды за ежедневную активность и задания.
- Задание подписки на канал проверяется через MAX API; прочие задания могут отправляться администратору на ручную проверку.
- Обмен ягод на монеты по курсу из Redis (по умолчанию 100:1).
- Монеты списываются за участие в активных розыгрышах; повторное участие блокируется на стороне Redis.
- История операций хранится в Redis.
- Администратор создаёт розыгрыши и подтверждает заявки.

## Игровой прогресс
- Посещения, серия подряд и контрольные отметки на 3, 7, 14 и 30 дней.
- XP и уровни начисляются сервером после подтверждённых действий; повторные события блокируются Redis.
- Награды за серии и уровни выдаются ягодами и попадают в существующий кошелёк и историю.
- Коллекция достижений показывает открытые и закрытые награды.
- Администратор настраивает XP, пороги уровней и ягодные награды.
- `api/cron/norka.js` отправляет ежедневные напоминания и сообщения о завершении розыгрышей. Для cron требуется `CRON_SECRET`.

## Сохранённые компоненты MAX
- `api/webhook.js` — webhook бота и приветствие с кнопкой открытия Норки.
- `api/setup-webhook.js` — регистрация webhook.
- `api/track-user.js` — уведомление администратору при открытии приложения с данными профиля MAX.
- `lib/max-api.js` и `certs/` — MAX API и сертификаты.

## Vercel environment
- `MAX_BOT_TOKEN`
- `MAX_WEBHOOK_SECRET`
- `WEBHOOK_BASE_URL`
- `KV_REST_API_URL` и `KV_REST_API_TOKEN` (или переменные Upstash)
- `NORKA_ADMIN_PASSWORD`
- `NORKA_CHANNEL_URL` (необязательно)
- `CRON_SECRET` (для защищённого ежедневного задания Vercel Cron)

После настройки переменных нужен новый deployment.

## Важно
В репозитории присутствует платёжный поток YooMoney: `api/norka-payment.js` создаёт заказ, а `api/yoomoney/notify.js` проверяет HMAC-SHA256 подпись уведомления и начисляет монеты через атомарную Redis-операцию. Наличие кода не означает, что реальный платёжный цикл проверен в production: перед приёмом платежей нужно провести контрольный платёж и сверить настройки уведомлений в YooMoney. До запуска денежных операций и розыгрышей с реальными призами отдельно проверьте юридическую модель, правила, налоги и требования платёжного провайдера. Подпись WebAppData MAX проверяется на сервере с ограничением срока действия. Начисление ежедневной награды, заявки на задания, обмен и участие в розыгрышах выполняются с Redis-защитой от повторных запросов.

GitHub Pages отдаёт `index.html`; API и Redis работают в Vercel.
