# Волна — музыкальное мини-приложение

Адаптивный музыкальный каталог с плеером. Аудиофайлы не хранятся в GitHub: в каталоге треков указываются только внешние HTTPS-ссылки.

## Что есть
- Поиск по названию, исполнителю и жанру
- Фильтры по жанрам
- Плеер: play/pause, следующий/предыдущий, перемотка, громкость, перемешивание и повтор
- Избранное хранится локально в браузере пользователя
- Адаптивная версия для телефона

## Как подключить свою музыку
1. Загрузите аудио в отдельное хранилище.
2. Получите публичную HTTPS-ссылку, которая ведёт непосредственно к файлу MP3/AAC/OGG.
3. В `index.html` найдите массив `tracks` в скрипте.
4. Замените поля `title`, `artist`, `genre` и `src`. Добавьте новые объекты для остальных треков.
5. Не коммитьте сами аудиофайлы в GitHub.

Пример записи:
```js
{id:"track-01",title:"Мой трек",artist:"Исполнитель",genre:"Чилл",cover:"c1",icon:"♫",src:"https://ваш-домен.example/music/track.mp3"}
```

## Где хранить аудиофайлы вне GitHub

- **Cloudinary** — простой старт: загрузить файл и использовать его HTTPS URL. Перед загрузкой проверьте поддерживаемые типы файлов, лимиты бесплатного тарифа и правила доставки аудио.
- **Supabase Storage** — объектное хранилище с публичными URL; удобно, если позднее добавите базу треков, пользователей и плейлисты. У бесплатного тарифа есть лимиты.
- **Bunny Storage + CDN** — вариант для раздачи медиа; проверьте текущие тарифы и расходы на хранение/трафик.
- **SoundCloud embed** — подходит, если достаточно официального встроенного плеера опубликованного трека. Это не прямая ссылка на MP3, поэтому текущий HTML-плеер не сможет использовать её как `src`.

**Рекомендация:** для простого каталога начните с Cloudinary; для будущей полноценной библиотеки с базой данных — Supabase Storage. Бесплатные тарифы и ограничения могут меняться.

Загружайте только музыку, на которую у вас есть права на хранение и потоковое воспроизведение. Доступность файла по публичной ссылке сама по себе не даёт права распространять музыку.

## Публикация
В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните. После завершения публикации GitHub покажет URL сайта.

В проекте оставлены демонстрационные MP3 с SoundHelix, чтобы проверить плеер. Они не являются вашей музыкальной библиотекой; замените их на собственные лицензированные файлы.
